# virtual-cell-challenge-2026

Repo for the [2026 Virtual Cell Challenge](https://virtualcellchallenge.org/), which focuses on zero-shot prediction.

Models included (`models` folder):
1. `baseline` folder: Target Scaling Baseline with constant c ("scuffed baseline"), as presented in "Signal, Bounds, and Baselines..." (Vollenweider, Bühlmann)

Data contained in this repo includes:
1. The VCC Validation Data

Datasets have been omitted due to large file size.
